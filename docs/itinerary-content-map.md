# Itinerary Content Map

## Purpose

This document converts the current trip plan into curriculum and product-planning inputs for the app.

Trip window captured from the shared itinerary:

- September 17-26, 2026

Primary trip regions:

- Tokyo
- Hakone
- Kyoto
- Hiroshima
- Nara
- Osaka
- return to Tokyo / Haneda

## Travel Shape

The trip is not a single-city stay. It includes:

- airport arrival and departure flows
- hotel and ryokan check-in patterns
- heavy train and station usage
- shrine and temple visits
- markets and food grazing
- shopping districts and souvenir shopping
- one or more special etiquette contexts such as onsen, meditation, and kaiseki dining

This means the app should prioritize:

- transit Japanese
- food and ordering Japanese
- shopping and requests
- polite interaction basics
- place-specific etiquette and vocabulary

## Stage Model for Each Area

Each area should be planned around four anchor stages:

- `Words`
- `Phrases`
- `Simple Conversation`
- `Natural Conversation`

These are milestone stages only. Additional build levels should be inserted wherever needed, especially because the user is starting with no Japanese background.

Example for `Airport`:

- Airport Words
- Airport Sign Recognition
- Airport Basic Phrases
- Airport Check-In Pattern Building
- Airport Simple Conversation
- Airport Clarification
- Airport Natural Conversation

Example for `Convenience Store`:

- Convenience Store Words
- Item and Category Recognition
- Convenience Store Basic Phrases
- Request and Quantity Building
- Simple Checkout Conversation
- Natural Checkout and Clarification

## Product Implication

The app should not only let the user browse by generic topic. It should also let the user browse by itinerary stop or city so the lessons feel like preparation for a specific upcoming day.
