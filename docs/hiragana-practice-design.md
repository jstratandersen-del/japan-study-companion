# Hiragana Practice Design

## Why this branch exists

Hiragana is a foundational reading skill, and the strongest worksheet-style approaches do not stop at copying characters. The effective pattern is:

1. learn a small sound set
2. reinforce with repeated sound-to-kana recall
3. read kana back into sound
4. use the same kana inside short real words

That pattern maps well to the game.

## Adapted worksheet model

The in-game version uses:

- `chart reference` via a tappable hiragana chart
- `sound recognition` prompts such as `Which hiragana is "ka"?`
- `reading recall` prompts such as `What sound is "け"?`
- `real-word reading` prompts such as `What does "すし" mean?`

## Current scope

The first pass covers:

- vowels
- K / S / T / N rows
- H / M / Y / R / W rows
- voiced sounds
- common combos
- short real words for food, greetings, and travel

## Notes

This is intentionally a separate foundation branch rather than being buried inside one trip category. It supports every later city and category in the app.
