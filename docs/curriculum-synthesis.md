# Curriculum Synthesis

## Purpose

This document combines:

- the core Japanese building blocks
- the area-by-area phrase inventory

The goal is to decide:

- where each building block should be introduced
- which area should reinforce it
- what intermediate steps are needed between single words and natural conversation

## Design Rule

Teach a building block in the place where it first becomes both:

- easy enough for a complete beginner to grasp
- reusable enough to matter in later areas

If something is broadly reusable, introduce it in foundations first.

If something is narrow and situational, introduce it inside the area where it is first needed.

## What Belongs in Foundations

These should be taught globally because they unlock many areas.

### Foundation 1: Social Survival

- yes / no
- excuse me
- thank you
- sorry
- please
- I do not understand
- one more time please

Best reason:

- these reduce friction everywhere immediately

### Foundation 2: Core Structure

- `desu`
- `desu ka`
- topic marker usage in simple fixed frames
- this / that / where
- what / where / how much

Best reason:

- these are the minimum parts for making sense of short phrases

### Foundation 3: Requests

- `... o onegaishimasu`
- `... kudasai`
- `misete kudasai`
- `oshiete kudasai`

Best reason:

- requests are required in airport, hotel, shopping, food, and directions

### Foundation 4: Numbers, Prices, and Time

- 1-10
- price recognition
- time basics
- person counts and item counts as needed

Best reason:

- counting recurs constantly in tickets, shopping, meals, and hotel stays

### Foundation 5: Location and Movement

- where is ...
- here / there
- right / left / straight
- go / come / get off / board

Best reason:

- these power the most common travel tasks

### Foundation 6: Clarification and Repair

- please speak slowly
- one more time please
- is this okay?
- can I use this?
- I do not know

Best reason:

- this is what keeps the learner functioning when comprehension breaks

## What Belongs Primarily in Areas

These should first appear in context.

### Airport

- boarding and check-in language
- passport and queue language
- arrival vs departure signs

### Hotel

- reservation and check-in phrases
- breakfast and room issue phrases
- luggage holding or forwarding

### Convenience Store

- bag / heating / payment flow
- this one / two please

### Trains and Stations

- platform questions
- transfer language
- route and pass confirmation

### Restaurant

- English menu
- ordering and recommendation language
- ingredient removal or allergy language
- check please

### Shopping

- size, color, try-on, stock, tax-free

### Shrine and Temple

- photo permission
- entry restrictions
- etiquette instructions

### Ryokan and Onsen

- meal timing
- bath timing
- etiquette phrases and signs

## How to Build from Basic to Advanced

The app needs an explicit bridge structure.

For each level:

1. `Words` sublevel
2. `Word Combinations` sublevel
3. `Basic Phrases` sublevel
4. `Pattern Building` sublevel
5. `Response Recognition` sublevel
6. `Simple Conversation` sublevel
7. `Clarification and Variation` sublevel
8. `Natural Conversation` sublevel

Inside each sublevel, the app should use internal components.

Typical component sequence:

1. vocabulary set
2. review
3. combination building
4. phrase building
5. recall or flashcard review

## What Each Step Means

### 1. Words

Example in `Trains and Stations`:

- station
- train
- platform
- exit
- ticket

Goal:

- recognize high-frequency nouns and signs

### 2. Word Combinations

Example:

- this ticket
- station exit
- reserved seat
- one ticket

Goal:

- connect isolated words into usable chunks

### 3. Basic Phrases

Example:

- where is the platform?
- one ticket, please
- does this train go to ... ?

Goal:

- produce short, complete travel sentences

### 4. Pattern Building

Example:

- swap destination names
- swap quantities
- swap ticket / pass / train nouns

Goal:

- avoid memorizing one frozen phrase only

### 5. Response Recognition

Example:

- platform number responses
- yes / no / additional charge / transfer there

Goal:

- understand the likely answer before attempting conversation

### 6. Simple Conversation

Example:

- ask which train
- hear platform
- repeat destination for confirmation

Goal:

- handle short guided exchanges

### 7. Clarification and Variation

Example:

- one more time please
- is this okay?
- can I use this pass?

Goal:

- recover when the first attempt does not work

### 8. Natural Conversation

Example:

- a faster station exchange with fewer scripted cues

Goal:

- handle realistic bounded travel interaction

## Component-Level Mastery

Components should enforce understanding before progression.

Rule:

- if a question is answered incorrectly, it moves to the back of the current component queue
- the learner must answer all items in that component correctly before moving to the next component
- the sublevel is only complete after every required component is cleared

This is the mechanism that turns exposure into mastery.

## Critical Teaching Constraint

Conversation should never be the first time a learner sees the underlying block.

Before any conversation level, the learner should already know:

- the key nouns
- the key question or request frame
- the likely answer types
- one repair phrase

## Practical Curriculum Decision

The strongest curriculum shape for this app is:

- teach reusable blocks globally
- teach travel-specific vocabulary inside areas
- build every area through multiple intermediate steps
- delay "natural conversation" until the learner has already seen the phrases, variations, and common responses in controlled form
