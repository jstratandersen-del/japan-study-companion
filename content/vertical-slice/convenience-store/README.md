# Convenience Store Vertical Slice

This folder contains the first authored content package for the `Convenience Store` category.

## Included

- level definitions
- sublevel definitions
- runtime-ready curriculum bundle

## Scope

The current authored pass focuses on the first Tokyo convenience store flow:

- `Conbini Basics`

## Curriculum Goal

This branch is meant to teach the most common language needed in a Japanese convenience store:

- store and shelf words
- common snacks, drinks, and ready meals
- short help questions
- checkout language
- small checkout requests like bags, heating, and receipts

## Runtime Bundle

The first completed runtime-ready bundle is:

- `runtime/convenience-store-c-l1-conbini-basics.json`

This file groups the convenience-store branch by:

- sublevel
- lesson level
- component
- questions or intro items

so the game can consume it the same way it consumes the restaurant and arrival branches.
