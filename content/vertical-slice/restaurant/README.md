# Restaurant Vertical Slice

This folder contains the first playable content package for the `Restaurant` vertical slice.

## Included

- level definitions
- sublevel definitions
- component definitions
- early question content
- runtime-ready level bundle

## First Slice Target

- `R-L1 Menu Basics`
- `R-L2 Ordering Basics`

## Current Curriculum Status

The original slice content was useful for interface testing but too difficult for a true beginner lesson.

The current authoring pass starts correcting that by:

- fully defining beginner components for `R-L1-S1 Food Words`
- reducing the first playable target to 5 core restaurant words
- delaying phrase-building until a later sublevel

## Authored Branch Status

The content pack now includes authored early-branch material for:

- `R-L1-S1 Food Words`
- `R-L1-S2 Menu Categories`
- `R-L1-S3 Reading a Simple Menu`
- `R-L1-S4 Asking What Something Is`
- `R-L2-S1 Pointing and Ordering One Item`
- `R-L2-S2 Ordering a Drink`

## Game-Ready Bundle

The first completed runtime-ready level bundle is:

- `runtime/restaurant-r-l1-menu-basics.json`

This file groups the first restaurant level by:

- sublevel
- component
- questions or intro items

so the game can consume it as a structured level instead of a flat note set.
