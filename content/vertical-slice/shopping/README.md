# Shopping Essentials

The first Tokyo Shopping branch for practical retail interactions.

## Structure

- `S1` Shopping Essentials
  - `S1-S1-L1` Store Words and Prices
  - `S1-S1-L2` Clothing and Sizes
  - `S1-S1-L3` Tax-Free and Payment
  - `S1-S1-L4` Gifts and Returns

Each lesson level follows the same playable rhythm:

1. Vocabulary introduction
2. Japanese recognition
3. Meaning check
4. Mixed review

The branch starts with the language needed in almost any store, then moves through clothes, checkout, tax-free shopping, gifts, and common purchase problems.
