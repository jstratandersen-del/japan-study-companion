# Arrival Vertical Slice

This folder contains the first authored content package for the `Arrival` category.

## Included

- level definitions
- sublevel definitions
- runtime-ready curriculum bundle

## Scope

The current authored pass focuses on the first real trip flow in Tokyo:

- `Airport Basics`
- `Transfer to City`
- `Hotel Check-In`

## Curriculum Goal

This branch is meant to teach the earliest survival Japanese needed right after landing:

- finding signs and key places
- understanding airport and station vocabulary
- navigating tickets, trains, and taxis
- checking into a hotel with a reservation

## Runtime Bundle

The first completed runtime-ready bundle is:

- `runtime/arrival-a-l1-arrival-essentials.json`

This file groups the arrival branch by:

- sublevel
- lesson level
- component
- questions or intro items

so the game can consume it the same way it consumes the restaurant branch.
