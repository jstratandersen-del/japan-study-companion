# Hiragana Foundations

This branch turns common paper hiragana worksheet patterns into in-game lessons.

The design goal is:
- introduce a small sound group
- practice kana selection from sound prompts
- practice reading kana back into sound
- reinforce with short real words

The current runtime bundle lives at:
- `runtime/hiragana-h-l1-foundations.json`

The served copy for the web prototype lives at:
- `apps/web/data/hiragana/hiragana-h-l1-foundations.json`
